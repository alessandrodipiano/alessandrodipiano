## Thesis Project

My thesis work focuses on quantitative medical imaging and predictive modeling.

In collaboration with a hospital radiology department, I am investigating whether diffusion MRI (IVIM-DWI) can be used to predict contrast-enhanced perfusion parameters derived from DCE-MRI.

The project involves:

- Radiomic feature extraction from MRI data  
- Exploratory statistical analysis (correlation and feature screening)  
- Regularized regression models (Elastic Net)  
- Gradient-boosted trees (XGBoost)  
- Bootstrap-based uncertainty estimation  
- Careful cross-validation to ensure reliable performance assessment  

The main objective is to study the relationship between diffusion-based biomarkers and perfusion parameters using statistically robust and reproducible methods.
